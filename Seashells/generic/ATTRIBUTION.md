# Generic Voices — Attribution

The clips in this folder are **bundled generic voice references** for The
Oracle's "Default Voices" picker. They are **not** user recordings; they are
copied from the demo voice files shipped with
[audio.cpp](https://github.com/0xShug0/audio.cpp) (`webui/voice/`), the
ggml-based inference engine The Oracle uses for its Vulkan backend.
