# The Oracle TTS 1.4.1 Candidate — Release Notes

This candidate restores access to ordinary Community workflows without
activation, while keeping the Studio render report behind its existing
entitlement. It also improves peak limiting, expands automated real-engine
smoke coverage, removes an unused Gradio demo dependency from the managed
installation, and refreshes third-party notices.

This is an engineering candidate, not an approved commercial release. Human
audio review, clean installation and upgrade qualification, candidate CI,
release artifacts, and legal/commercial approval are still outstanding. See
[Final Release Readiness](FINAL_RELEASE_READINESS.md) and
[Known Issues](KNOWN_ISSUES.md).
