# Product Offer Assessment — Owner Review Required

## What the candidate actually provides

The 1.4.2 candidate is a local-first desktop application and CLI for preparing
and rendering labeled dialogue with Chatterbox. Community retains rendering,
voice selection and blending, Recording Studio, project workflows, previews,
and the existing correction and batch tools. Studio currently adds an
`studio_features` entitlement; the first verified gated command is
`render-report`, which measures a completed render and produces a technical
conformance report. Activation is optional for ordinary Community workflows.

## Recommendation

For this limited alpha, use **Option A: founder-supported alpha** as the
working positioning. The engineering evidence does not yet establish that the
single gated report command is a sufficiently valuable Studio bundle to
justify a differentiated premium tier. The alpha can be described as
experimental and local-first, with direct support and structured tester
participation, only if the owner confirms that support and participation offer.

Do not claim a price, refund policy, service level, license grant, commercial
usage right, or finalized tier until the owner and counsel approve those terms.
The draft EULA and third-party obligations remain release blockers.

## Studio differentiation candidates

The existing `render-report` capability is the only candidate verified in this
pass. It can be considered for Studio if it provides clear value to the target
customer. Batch tools and voice/project workflows are already part of the
broader product surface and should not be re-labeled as exclusive without an
owner-approved entitlement and user-value case. Professional presets or new
automation would require product decisions and implementation, so they are
deferred.

## Owner decisions

1. Approve or replace the founder-supported alpha positioning.
2. Set pricing, support scope, refund policy, and permitted use with counsel.
3. Decide whether `render-report` alone warrants Studio exclusivity.
4. Approve final EULA and third-party compliance before any sale or publication.
